# Bootstrap Projects — GoMyCode Checkpoints

Two responsive webpages built with Bootstrap 5.3, each with its own custom stylesheet on top. The
first is a restaurant site, focused on the grid system; the second is a travel agency, focused on
the components — accordion, carousel, offcanvas, modal. Same framework both times, deliberately
different-looking results, because all the visual work is in `styles.css` rather than in Bootstrap
defaults.

| Project | Folder | Focus |
|---|---|---|
| **Delicious Bites** — restaurant | [`restaurant/`](restaurant/) | Bootstrap grid system |
| **Atlas Horizons** — travel agency | [`travel-agency/`](travel-agency/) | Bootstrap components |

Open [`index.html`](index.html) for a landing page linking both, or open either project's
`index.html` directly in a browser.
